# VeriMat 复赛实验报告：热电材料构效关系发现的全自动闭环评测

预注册 `semifinal-v2-thermo`（冻结于 2026-08-28，先于任何计分运行）｜正式结果 `results/semifinal_v2/`

## 1. 摘要

本实验对 VeriMat 证据与反证驱动的文献发现管线进行了**预注册、全自动化闭环评测**（无人工复核）：系统在 2000–2021 热电文献语料上抽取构效关系并输出带验证状态的候选主张，由时间截断文献预言机（2022–2025 验证窗）自动裁定真值，六个预注册方法变体在统一语料快照、统一检索快照、统一 token 预算与统一随机种子下对照。

核心结论（n=258 主张）：

- **决策准确率**：V0 vanilla-RAG 0.1473（恰为 supported 先验占比）→ V2 双向检索+CEDG 0.4826；
- **状态机是承重组件**：V2 对 V1 **+0.3236（Holm p=0.0003）**，V3 对 V0 基线 +0.314（p=0.0003）；
- **诚实负结果**：Pareto-MCTS 与成分数据库校验无显著边际贡献（p=1.0 / 0.63）；
- **证据可回放**：六方法回放精度全部 **1.0**；
- **新颖性可检验**：already-known false-gap rate = 0.1667；
- 产出 **44 个发现包**（可证伪陈述+边界+证据定位+最小验证实验）；
- 全部方法低于 3M token 预算（合计 1.28M）。

## 2. 科学问题与任务

方向三「材料科学文献驱动的科学发现智能体」，基础任务（检索筛选/知识抽取/ResearchGap 识别/结构化报告）+ 进阶路线 A「构效关系发现」。VeriMat 把文献调研表示为**主张的状态估计**：候选关系携带边界、支持/反证证据与验证状态，由确定性状态机（CEDG）而非模型自报置信度裁决终态。

## 3. 系统与方法

管线：问题契约 → 语料冻结(Sciverse, SHA-256) → 关系抽取（引文逐字门+数值门+封闭词表）→ 主张投影 → 六方法并行验证 → 时间窗预言机 → 发现包 → 确定性评分 → 报告。语言模型只产生候选与判断；定位、截断、状态、预算、终态由确定性组件裁决。

六方法：V0 vanilla-RAG（盲接受）/ V1 双向检索 / V2 +CEDG / V3 全量（+Pareto-MCTS+DB）/ A1 无MCTS / A2 无DB。共享同一次缓存抽取（相同主张集），差异全部归因于验证层。

**时间窗预言机**（核心评测设计）：每个主张在 2022–2025 验证窗以 4 条预注册模板检索，逐文献由模型判定（须逐字引文命中，否则作废留档），确定性聚合（矛盾>收窄>支持>未决）。方法侧验证检索硬截断 2021——**不可能通过偷看未来得分**。

模型路由：Linux + OpenCode server（HOME 隔离，工具全禁用）+ zhipuai/glm-5.3-flash；与 Windows 上 Claude Code（Opus 5，v1 开发运行）共享同一 `StructuredModelTransport` 协议——跨平台跨模型可替换是架构性质，两次运行均公开。

### 6.4 Research Gap 新颖性

规则引擎 + narrator 产出 9 个 Gap（novel 6）。验证窗检索+裁定：1 个"新颖"缺口已被后续文献解决 → **already-known false-gap rate = 0.1667**。"已知"判定强制携带逐字引文，否则构造期即拒绝。

### 6.5 发现包（可证伪交付物）

V3 存活主张生成 **44 个发现包**：可证伪陈述、适用边界、哈希定位证据、反证考量、最小验证实验与支持性预期。证据不可回放的包被拒绝留档（`packs_refused.json`）。

## 7. 解读

1. **确定性状态机是增益来源**：V1=V0 说明"把反证摆到模型面前"不改变行为；CEDG 裁决把反证转化为 +0.32 的决策差异（两轮实验、两种平台均复现）。
2. **诚实负结果**：MCTS 与 DB 校验在本规模无显著边际（p≥0.44），随全部数据公开。
3. **校准是下一个迭代点**：启发式置信的 Brier ≈ 0.46–0.49。
4. **反证召回与准确率是独立维度**：A2 召回 0.27 与准确率 0.45 并存，怀疑策略可调。

## 8. 局限

预言机依赖模型判定（引文门+全文明细公开可抽查）；46% 主张真值 unresolved 压低所有方法的上限（配对统计不受影响）；单域单路由单快照；MCTS/DB 结论不能外推到更大规模。
